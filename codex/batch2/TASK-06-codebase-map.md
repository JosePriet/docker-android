# Task 06: whole-codebase map, dead code and refactor report

The mod is ~90 Java files in `src/java/fr/testudo/spacecorsair/mod/`, patched into the closed game by `src/patch/hooks*.py` (read only, never run), plus `server/rendezvous/`, `scripts/`, `tools/sim/`, `i18n/`.
1. **Hook map**: for every hook script, which base-game class/method it patches, which mod method it calls, and when it runs (frame, event, load). Table with file:line on both sides.
2. **Call graph** of the mod (static analysis, generated by a script you commit under `codex/tools/b2-06/`), rendered as SVG per subsystem: combat, police, refit/ships, art/fx, UI, save, network, prologue.
3. **Dead code**: methods, fields, classes, data rows and art files under `work/modart/` that nothing reaches (account for reflection and hook calls; mark each CONFIRMED/SUSPECTED). Same for `scripts/` and `tools/`.
4. **Duplication and risk**: copy-pasted logic, the same constant defined in several places with different values, static state never reset between sessions/profiles, data tables that disagree with each other (e.g. hull stats in two places).
5. **Refactor plan**: ranked list, each with effort, risk and what it unlocks. Then actually do the top 2 lowest-risk refactors on your branch with zero behaviour change, proven by compiling and by tests you add that pin behaviour before and after.
Output `codex/out/b2-06/` (report.md, hookmap.csv, deadcode.csv, svg/).
